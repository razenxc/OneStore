# OneStore

## Project Setup Guide (ASP.NET Web API + Docker + PostgreSQL(EFcore))

### Prerequisites

- Docker

---

### 1. Clone the Repository

```sh
git clone https://github.com/razenxc/OneStore
cd OneStore
```

---

### 2. Configure environment variables

- Duplicate`example.env`  and rename to `.env`

- Fill needed fields

## 3. Run docker compose

- `docker compose up -d`
